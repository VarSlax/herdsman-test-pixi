# Herdsman

**Herdsman** is a mini-game built with **PixiJS**, where the player controls a hero, collects animals, and delivers them to the yard. The project is written in **TypeScript** and uses a modern frontend stack with **Vite** and **ESLint/Prettier** to maintain code quality.

---

## Technology Stack

- **PixiJS 8.8.1** — main 2D rendering engine  
- **@pixi/sound 6.0.1** — audio management  
- **@pixi/ui 2.2.2** — UI elements  
- **@esotericsoftware/spine-pixi-v8 4.2.74** — Spine animations  
- **motion 12.4.7** — animations and transformations  

**Development Tools:**

- **TypeScript 5.7.3** — strong typing  
- **Vite 6.2.0** — project bundler and dev server  
- **ESLint + Prettier** — code quality and formatting  

---

## Installation

Clone the repository:

```bash
git clone git@github.com:VarSlax/herdsman-test-pixi.git
cd herdsman-test-pixi

npm install
```

## Running

```bash
npm run start
```
